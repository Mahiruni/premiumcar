# Habesha Market

Ethiopia-first classifieds marketplace inspired by the interaction patterns of leading Nordic classifieds platforms, with original branding, UX, and implementation.

## Stack
Next.js 15 · React 19 · TypeScript · optional Supabase backend

## Local setup
```bash
npm install
npm run dev
```

Set `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` when connecting a Supabase project. The UI includes a local demo mode so the marketplace can be previewed without credentials.
